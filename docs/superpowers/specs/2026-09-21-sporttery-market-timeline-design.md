# 中国竞彩单场赔率时间线设计

## 目标

为历史比赛提供独立的“市场详情”页面，完整展示中国竞彩已采集的赔率时间序列。用户需要看到每种玩法在不同发布时间的赔率，而不是只看到最后一条收盘快照，并能直观看出相邻快照的上涨、下降或不变。

本次只展示已落库数据，不在浏览页面触发体彩网络请求，也不改变训练数据定义。

## 用户流程

1. 用户在历史比赛列表点击“市场详情”。
2. 页面进入该场比赛的独立详情路由，保留返回历史列表的入口。
3. 页面顶部展示联赛、赛季、比赛日期、主客队、半场与全场比分。
4. 页面依次展示胜平负、让球胜平负、比分、总进球和半全场。
5. 每种玩法以表格呈现：列为结果选项，行为官方发布时间，单元格为赔率。
6. 相邻发布时间的同一选项发生变化时，用箭头和文本可访问标签表示升降；颜色只作辅助。

只有让球胜平负而没有普通胜平负的比赛仍能正常显示。让球玩法按盘口拆分为独立表格，并在标题和表格中明确盘口值。

## 路由与导航

- 历史列表保持现有分页与筛选行为。
- “市场详情”进入 `#history/match/<match-id>`。
- 返回操作恢复之前的历史列表 URL，包括赛季、联赛、球队、页码和每页条数。
- 详情页直接刷新时也能根据比赛 ID 独立加载，不依赖列表内存。

## 后端接口

新增只读接口：

```text
GET /api/data/matches/{match_id}/market-history
```

响应包含：

- 比赛身份、联赛、赛季、日期精度、主客队和赛果；
- 按 `market_type + handicap` 分组的市场；
- 每组稳定、有业务意义的结果列；
- 按 `captured_at` 升序排列的全部赔率快照；
- 来源、提供方和时间精度等追溯信息。

接口通过核心比赛的 `source_match_id` 关联 `sporttery_matches`，再读取：

- `sporttery_bonus_snapshots`
- `sporttery_bonus_outcomes`

不得从通用 `market_snapshots` 构造时间线，因为该表目前只保留供列表使用的最新快照。查询必须使用参数绑定，未知比赛返回 404；存在比赛但没有赔率时返回比赛信息和空市场数组。

## 数据排序与显示规则

市场顺序固定为：

1. 胜平负
2. 让球胜平负
3. 比分
4. 总进球
5. 半全场

结果列使用业务顺序，而不是字符串排序：

- 胜平负、让球胜平负：胜、平、负；
- 比分：主胜比分、平局比分、客胜比分、胜其他、平其他、负其他；
- 总进球：0、1、2、3、4、5、6、7+；
- 半全场：胜胜、胜平、胜负、平胜、平平、平负、负胜、负平、负负。

赔率统一显示两位小数。发布时间按中国时区显示秒级时间。缺失结果显示破折号，不使用 0 代替。

涨跌由前端比较同一市场、同一结果列的相邻快照得到：

- 当前值大于上一值：上升；
- 当前值小于上一值：下降；
- 相等或没有上一值：不显示方向。

## 前端结构

新增独立页面组件和三个清晰边界：

- `MatchMarketHistoryPage`：负责路由、加载、错误与返回导航；
- `MarketHistorySection`：负责单个玩法标题、盘口和追溯信息；
- `OddsTimelineTable`：负责结果列、发布时间行、赔率与涨跌标记。

比分表允许自身横向滚动，其他玩法尽量在内容宽度内完整显示。每个玩法是全宽分区，不使用卡片套卡片。表头保持可读，数值使用等宽字体和稳定列宽，窄屏保留水平滚动条。

详情页遵循现有 `DESIGN.md`：浅色研究工作台、球场绿作为结构色、荧光色仅用于状态强调，不模仿彩票网站的红色品牌外观。

## 状态与错误处理

- 加载：保留详情页稳定骨架尺寸并显示文字状态；
- 未找到：说明比赛不存在或已被移除，并提供返回历史列表；
- 无赔率：仍显示比赛信息，明确提示“该场比赛没有已采集的赔率记录”；
- 请求失败：保留当前页面并提供“重新加载”；
- 部分结果缺失：仅对应单元格显示破折号，不隐藏整行或整张表。

## 性能

历史列表继续只返回轻量的最新赔率，不把上万场比赛的完整时间线塞入分页响应。完整快照仅在进入单场详情时按需查询。单次查询限定一个比赛 ID，并使用现有外键和比赛 ID 关联，避免全表扫描后在 Python 中过滤。

## 测试

后端测试覆盖：

- 单场多个玩法、多个发布时间完整返回；
- 盘口分组和业务排序；
- 未知比赛 404；
- 有比赛无赔率返回空数组；
- 不同比赛的数据不能串场。

前端测试覆盖：

- 从历史列表进入详情并能返回原筛选位置；
- 只有让球胜平负时仍显示完整表格和盘口；
- 比分、总进球、半全场列顺序及中文标签；
- 相邻快照涨跌标记；
- 加载、空数据、404 和可重试错误；
- 大量比分列不会压缩重叠，窄屏可横向滚动。

## 非目标

- 不重新抓取或修复缺失赔率；
- 不在本阶段实现模型训练或预测；
- 不仿制竞彩网的页头、广告、品牌颜色和其他导航；
- 不把完整赔率时间线重新塞回历史比赛分页接口。
